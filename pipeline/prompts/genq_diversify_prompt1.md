## Task
Generate **diversified variations** of a given coding question that enhance both diversity and complexity.

## Objective
Take an existing coding question and create multiple variations that:
- Maintain the same core programming concepts and skills being tested
- Apply to completely different contexts, scenarios, or domains
- **Increase complexity** through additional requirements or constraints
- **Enhance diversity** through novel problem formulations
- **Use the specified programming language** consistently across all variations

## Guidelines

### Core Requirements
- Preserve the fundamental programming skills and concepts being assessed
- Ensure each variation is solvable with the same level of programming knowledge
- Maintain clear and self-contained problem descriptions
- **Use the target programming language** specified in the input

### Diversity Enhancement
- **Novel Context**: Present problems in unique scenarios or application domains
- **Multi-faceted Approach**: Require combination of multiple programming concepts
- **Creative Problem-solving**: Encourage innovative solutions beyond straightforward implementations
- **Domain Variation**: Apply to completely different industries, use cases, or user types

### Complexity Enhancement
- **Advanced Requirements**: Add sophisticated constraints or performance requirements
- **Multi-step Process**: Include additional intermediate steps or transformations
- **Edge Case Handling**: Incorporate scenarios that test boundary conditions
- **Optimization Challenges**: Specify performance constraints requiring efficient solutions
- **Language-specific Features**: Utilize advanced features and best practices of the specified language

## Input Format
**Original Question**: {ORIGINAL_QUESTION}
**Programming Language**: {LANGUAGE}

## Output Requirements
Generate **one diversified variation** of the original question. The variation should:
1. Maintain the same core programming skills being tested
2. Apply to a completely different context, scenario, or domain
3. **Increase complexity** through additional requirements or constraints
4. **Enhance diversity** through novel problem formulations
5. **Use the specified programming language** consistently
6. Feel like a natural, real-world scenario from a different setting
7. Be meaningfully different from the original and other variations
8. Do not include sample solutions or implementation details in the question since this is meant to be a coding challenge for assessment
